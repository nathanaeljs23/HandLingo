# Model Assets

This directory holds the TF.js model and calibration config loaded by the browser at runtime.

## Required files

| File | Description |
|---|---|
| `model.json` | TF.js model topology (generated by converter) |
| `group1-shard1of1.bin` | TF.js weight binary |
| `inference_config.json` | Calibration metadata (temperature, threshold, label_map) |

## Conversion (run once, from the project root)

```bash
pip install tensorflowjs

tensorflowjs_converter \
  --input_format=keras \
  artifacts/sign_language_gru_model.keras \
  frontend/public/model

cp artifacts/inference_config.json frontend/public/model/inference_config.json
```

The converter produces `model.json` + one or more `.bin` weight shards.
The model is served as a static asset — no backend involved.
